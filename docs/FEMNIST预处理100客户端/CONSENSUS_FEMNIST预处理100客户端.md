## 2. 技术实现方案和技术约束

### 参数配置方案
基于数据分析确定最优参数：
- **s_frac**: 0.028 (100/3597≈0.0278，确保恰好100个客户端)
- **tr_frac**: 0.8 (80%训练数据，20%测试数据)
- **val_frac**: 0.1 (从训练集中分出10%作为验证集)
- **seed**: 12345 (确保可重现性)

### 执行命令
```bash
cd /root/autodl-tmp/FedGMM_ICML2023v2.14retry/data/femnist
python generate_data.py \
    --s_frac 0.028 \
    --tr_frac 0.8 \
    --val_frac 0.1 \
    --seed 12345
```
